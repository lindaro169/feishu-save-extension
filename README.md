# 飞书文档转存（Chrome 扩展）

把**只读 / 禁止复制**的飞书文档，整篇原样转存到自己的飞书空间，**图片真正嵌入**（转成你自己空间里的图片资源，不是外链，源文档删了也不影响）。

零配置：不需要创建飞书应用、不需要填 App ID / Secret，直接使用你当前浏览器里已登录的飞书身份。

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions/` 回车
2. 打开右上角「**开发者模式**」开关
3. 点左上角「**加载已解压的扩展程序**」，选择本目录（`feishu-transfer-extension`）
4. 打开任意一篇飞书文档，右下角会出现蓝色按钮「**⬇ 转存此文档**」

> 提示：建议把它固定到工具栏（拼图图标 → 图钉），方便随时看到。

## 使用

1. 打开你要转存的飞书文档（只要你能看到内容就行，只读也可以）
2. 点右下角「⬇ 转存此文档」
3. 等进度走完（长文档 + 多图会需要几分钟，期间**不要切换走该标签页**，切走了浏览器会限流导致图片加载不出来）
4. 完成后面板会给出新文档链接，点开即是转存好的副本（在你的「我的空间」里）

## 工作原理

1. 在文档页里滚动一遍，把虚拟渲染的正文块全部收集下来
2. 把页面里所有图片（飞书内链 / blob）下载下来转成 base64 内嵌进 HTML
3. 调飞书网页端自己的导入接口 `parse_html`，由飞书把 HTML 变成一篇新文档（图片由飞书自己重新入库 → 真正嵌入）
4. 轮询结果拿到新文档链接

## 已知限制

- 只支持飞书云文档（`/wiki/`、`/docx/`），暂不支持表格 / 多维表格 / 幻灯片
- 文档超过 25MB 会提示过大；单张图片超过 8MB 会被跳过
- 画板（whiteboard）、第三方网页嵌入等特殊块可能丢失或降级为截图/占位
- 转存过程中**不要切走标签页**：后台标签会被浏览器限流，导致图片加载不出来
- 飞书内部接口可能随版本调整，若某天失效需要更新选择器或参数
- 转存会遵守你的账号实际可见内容：你打不开的文档自然也转不了


## 更新说明

**v1.2.0**
- 附件文件块（`.txt` / `.md` / `.csv` 等文本类）→ **内容自动内联为代码块**（提示词不会再丢）
- 视频块 → 生成带播放/下载链接的占位（HTML 导入不支持内嵌视频）
- 清除飞书页面自身的 UI 垃圾（标题栏作者/修改时间、评论层、"Unable to print" 等隐藏占位）
- 标题兼容中英文界面后缀（`- 飞书云文档` / `- Feishu Docs`）并去掉 `.html`
- 清除零宽字符

**v1.1.0**：改用分块上传（prepare → 逐块 merge_block → finish → parse_html(fileToken)），弱网更稳、支持到 60MB

**v1.0.1**：提交增加自动重试与超时


**v1.4.0**
- 素材块（附件/视频）统一按真实 MIME 处理：
  - 文本类（.txt/.md/.csv…）→ 内容内联为**代码块**
  - **视频** → 下载后**分块上传到你自己云空间**，文档里给出名字 + 指向你自己副本的链接
    （飞书 HTML 导入不支持内嵌视频播放块；若需文档内真播放块，把云空间里那份视频拖进文档即可）
  - 其它二进制 → 标注名称与大小
- 修复：素材块渲染状态不稳定导致的漏采/误判（改为等 token 渲染出来再采集，并按 token 去重）

**v1.3.0**
- 按文档内真实 Y 坐标排序（修复视频/附件块顺序错位）
- 标题与正文清除零宽字符；清除飞书 UI 样板句（"This document hasn't been mentioned by others yet."）


**v1.5.0**
- 素材（尤其视频）改为**分片(Range)下载 + 每片自动重试**：2MB 一片，弱网/代理掐连接也能续着下完
  （修复：单次 9.5MB 下载被 `net::ERR_HTTP2_PING_FAILED` 掐断导致视频拿不到）
- 错误提示补充网络中断说明

**v1.4.0**
- 素材块按真实 MIME 分流：文本→代码块；视频→下载后分块上传到你自己云空间 + 文档内给出链接；其它→标注


**v1.7.0（视频真正落进文档）**
- 转存完成后：自动把视频下载到本地 → 打开新文档 → 通过 **Chrome 调试协议(CDP)** 发送"可信"鼠标与拖拽事件，
  把视频作为**原生视频播放块插入到文档里原来的位置**（合成事件落点不可控，必须走 CDP）。
- 新增权限：`downloads`（把视频落盘）与 `debugger`（发送可信事件）。
  ⚠️ 启用/更新此版本时 Chrome 会提示需要新权限（含"调试"类权限），需要你手动允许。
  插入过程中 Chrome 可能短暂显示"扩展正在调试此标签页"的提示条，插入结束会自动断开。
- 若定位不到原位置（如占位段落被删），视频会落在文档末尾。

**v1.5.0** 素材分片(Range)下载 + 每片重试（弱网可续传）

**v1.6.0**（合成拖拽方案，落点不可控，已被 v1.7.0 取代）


**v2.4.0（视频自动落位）**
- 表格单元格内的视频/附件占位 → 重建时**移到表格正下方**（飞书编辑器不接受把文件拖进单元格），从而可被自动插入为原生播放块
- 定位元素修正：只取承载占位文字的小段（此前会误选整篇容器，导致坐标失效）
- 视频插入：按索引逐个定位"第 N 个【视频】占位" → 真实点击定位光标 → 真实拖放（CDP），**每个视频落在自己的占位处**

- `content.css` —— 按钮与面板样式
